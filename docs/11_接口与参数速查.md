# 09 · 接口与参数速查

装配、接线、调试时随手查这一页。

---

## 1. 舵机 ID 规划

```text
右腿   10 右髋yaw · 11 右髋roll · 12 右髋pitch · 13 右膝 · 14 右踝
左腿   20 左髋yaw · 21 左髋roll · 22 左髋pitch · 23 左膝 · 24 左踝
头颈嘴 30 脖pitch · 31 头pitch · 32 头yaw · 33 头roll · 34 鸭嘴
机身IMU 200（仅整机集成版，挂在舵机总线上；桌面调试版 IMU 走主控 I²C，不用此 ID）
```

鸭嘴（34）是第 15 轴，**不参与走路策略**，由上层逻辑单独开合。

## 2. HD-1910 舵机关键参数

> 以 HD-1910 系列规格为参考（你的套件为 C018 批次，具体以随附规格书为准）。

| 项目 | 参数 |
| --- | --- |
| 类型 | 恒力空心杯总线舵机，金属齿 |
| 工作电压 | **4 – 8.4 V**（本套件用 7.5V 适配器） |
| 堵转扭矩 | 约 **12 kg·cm @ 6V**（约 1.18 N·m） |
| 额定扭矩 | 约 3 kg·cm @ 6V |
| 空载转速 | 约 92 rpm @ 6V |
| 减速比 | 320 : 1 |
| 编码器 | 12-bit 磁编码（0–4095，中位约 2048） |
| 接口 | **AMP2.0-3P** |
| 协议 | 飞特 TTL 半双工，8N1，数字包 |
| 通信波特率 | 统一设为 **1 Mbps** |
| 反馈 | 位置 / 速度 / 电流 / 电压 / 温度 / 负载 |
| ID 范围 | 0–253（出厂常见 ID 1） |

## 3. ⚠️ 针序对照（接线必看）

| 针位 | HD-1910（AMP2.0-3P） | Dynamixel / 飞特 HL 等 |
| --- | --- | --- |
| 1 | **Signal 信号** | GND 地 |
| 2 | Vcc 电源 | Vcc 电源 |
| 3 | **GND 地** | Signal 信号 |

> HD-1910 与 Dynamixel 针序**相反**，不能按 Dynamixel 线序直插。接 AMP2.0 转 5264 转接线前务必核对。

---

## 4. 波特率寄存器值对照（飞特 / Dynamixel 同类）

| 寄存器值 | 波特率 |
| --- | --- |
| 1 | 57 600（常见出厂默认） |
| 2 | 115 200 |
| **3** | **1 000 000（1 Mbps，本项目用）** |
| 4 | 2 000 000 |

> 出厂默认常不是 1 Mbps。用当前波特率扫到后，改成 1 Mbps 再统一使用。

## 8. 控制契约（软件）

| 项 | 值 |
| --- | --- |
| 控制频率 | 50 Hz |
| 观测维度 | 61（陀螺 3 + 重力投影 3 + 关节位置 14 + 关节速度 14 + 上一动作 14 + 指令 13） |
| 动作维度 | 14（14 个走路关节，不含鸭嘴） |
