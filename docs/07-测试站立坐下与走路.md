# 07-测试站立、坐下、走路等功能

[返回首页](../README.md) · 上一章：[标定 HOME 与 IMU](06-标定HOME位与IMU.md) · 下一章：[仿真训练](08-仿真训练.md)

**目标：**在实物上逐级验证卸力、站立、坐下和低速行走。每一级通过再进入下一级，把现象与数据写入验收记录。

本教程不把软件预检、悬空摆腿、视频演示或别人的成功记录当成本机验收。

## 1. 开始前的条件

- 15 颗舵机和 IMU 数据新鲜，无持续掉线、校验错误或超时。
- 运动模式、标定与模型合同正确；选用模型身份能从运行端确认。
- 电池电压及输出能力匹配，电池、主控、IMU、散热和脚底已固定。
- 当前姿势已知，人员能托稳机体，周围没有台阶、桌沿和线缆绊脚。
- 先在平整、硬质、防滑地面测试，保护绳只防摔，不把机器人一直向上吊起。
- 网页“卸力”可操作，电源开关可接近，暂时关闭手柄和其他控制源。

“当前姿势未知”“主程序没回话”或“卸力未确认”时，**不继续点站立和行走**。先按附录恢复通信并确认实际状态。

## 2. 第一级：卸力与状态确认

1. 托住机体，清空网页速度输入。
2. 点“卸力”，等运行端读回确认全部关闭扭矩。
3. 看实际关节是否放松，位置和 IMU 仍有新鲜数据。
4. 确认状态一致再继续。仅有“命令已接收”不代表全部关节已经卸力。

不通过：停止后续动作，检查总线及失效设备。断开浏览器、停止服务、拔掉电脑网络都不能代替卸力。

## 3. 第二级：站起来 / HOME 保持

1. 机器放地、双脚接触地面，人员托住躯干。
2. 确认零速度、无其他策略，点一次“站起来”。
3. 观察实际关节逐步进入 HOME，并等待页面确认完成。
4. 从短时观察开始，逐步增加到约 10 秒、30 秒的保持测试。时间是本教程的检查安排，不代表官方稳定性保证。
5. 检查左右脚受力、脚底贴合、机体姿态、关节跟踪、电压和温度。没有明显顶限位、持续抖动或温升失控后，再逐步减少手的支撑。

不通过：扶稳、卸力、记录。某一轴反向或明显偏离时，查 ID、零位、方向、HOME 与限位，不先提高 P 或放大动作幅度。

## 4. 第三级：坐下，再站起

先确认当前配套版本支持何种坐站流程：有的由专用坐站策略完成，有的有固定姿态过渡。不要把行走 ONNX 同时当成坐站模型。

1. 从已确认的站姿开始，点一次“坐下”。
2. 看膝、踝、头颈和电池是否与外壳/地面干涉，等待实物和页面都到坐姿。
3. 按该版本允许的流程再站起，确认重新进入 HOME。
4. 完成一次后再增加次数，不在过渡中连续切换按钮。

“坐下”并不必然等于卸力。要搬动或结束测试，仍需扶稳后单独卸力并确认。

## 5. 第四级：开启行走策略，先零速度观察

1. 先站稳，确认行走用途选中了正确的模型，实际回读一致。
2. 速度输入保持零，点一次“开始走”。
3. 观察运行端是否进入策略执行、状态持续更新，机体是否能保持平衡。
4. 零速度时模型可能主要保持姿态，不一定原地踏步。不能仅凭脚没有抬起判断“没运行”。

不通过：停止策略、扶稳、卸力，核对是否仍在标定模式、模型运行器是否启用、当前模型是否确实选用、观测与执行合同是否匹配。

## 6. 第五级：非零速度与真实落地行走

1. 在人员保护下给一个很小、短时的前进输入，随时松回零。
2. 先观察少量步数，不马上测试转弯、快速侧移或大幅头部动作。
3. 看是否真正移动、双脚是否合理交替、脚底是否打滑，是否靠保护绳吊着才有动作。
4. 回零后确认能停稳，再测试短距离前进、后退、小角度转向。
5. 记录速度输入、模型版本、机体姿态、电压、关节反馈、异常和地面条件；稳妥后再逐步增加时长。

关节突然冲限位、摔倒、总线大量丢包或主程序失联时，先保护机体并卸力；失联无法确认卸力且现场无法控制时，用可接近的电源开关切断驱动供电。不要追着连续发动作。

## 7. 常见现象怎么判断

| 现象 | 先检查什么 | 不要直接得出的结论 |
| --- | --- | --- |
| 点站起来没反应 | 网页连接、最新回读、当前姿势、日志拒绝原因、总线是否仍被 Studio 接管 | 不直接认定舵机坏或模型坏 |
| 能站能坐，开始走后地上不动 | 先确认策略正在执行，再确认有非零速度输入；对照目标、反馈、实际轴、电压和 IMU | 不直接提高增益或动作幅度 |
| 地上不走，拿起来摆腿 | 悬空与承重的跟踪差异、供电压降、舵机模式、安装干涉、脚底/重心、模型适配 | 悬空摆腿不算行走验收 |
| 回读位置变化，输出轴不动 | 真实设备/ID、舵盘连接、控制模式、保护状态 | 不把回读当作机械成功 |
| 一动就断网或重启 | 动作前后电压、主控日志、温度、HAT 降压与连接器 | 不只凭“电源额定电流很大”排除供电 |
| 重启后读不出姿势 | 新鲜样本、扭矩确认、丢 ID、标定持久化、启动阶段 | 不反复点击站起来 |

“开始走”后的效果判断至少同时包含：**模式与策略、速度命令、目标与反馈、实物运动、供电与 IMU**。缺少哪项就先补哪项证据。

## 8. 扩展功能与结束流程

基础动作稳定后，再逐项加入手柄、头嘴动作、语音和摄像头。一次增加一种功能，重复站立与短时试走，检查是否影响主控温度、控制节拍、总线和 SSH。

踢球、翻滚、捡取、倒地起身等必须有对应模型、空间和机械验证，不作为首次装机必测项目。

结束时：速度回零 → 按配套流程停止行走 → 能正常坐下则先坐下 → **托稳机体、卸力并确认** → 保存日志 → 正常关闭系统 → 按供电方案断开电池。

在瑞莎终端正常关机：

```bash
sudo poweroff
```

系统关机不代表 HAT 和舵机电源已经物理切断。网页失联也不构成关机成功的充分证据，需结合本机状态检查。

## 9. 本章验收

- [ ] 卸力、站立、坐下、再次站起均经实物与回读确认。
- [ ] 零速度策略保持和非零速度输入分别测试。
- [ ] 在真实地面完成短距离行走、停止和有限转向。
- [ ] 没有靠悬空或持续上提支撑替代承重验收。
- [ ] 异常、温度、电压、模型和地面条件有记录。
- [ ] 重启后复查通过，扩展功能没有破坏基础稳定性。

想了解或修改步态，再进入 [08-仿真训练](08-仿真训练.md)。使用已有配套模型的客户不必先训练才能完成本章。
