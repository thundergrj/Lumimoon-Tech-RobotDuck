# 接口与参数速查

[返回首页](../../README.md)

本表是教程主线的速查，不代替当前 PCB、舵机固件与模型合同。

硬件主线固定为 **瑞莎 ZERO 3W + 飞特 HD-1910-C001 + 配套 HAT**；完整数量、C001 参数及物料确认状态见[本套 BOM](../../bom/BOM-ZERO3W-HD-1910-C001-HAT.md)。后文“HD1910”是 C001 的简称。

## ID 与总线

| 对象 | 约定 |
| --- | --- |
| 右腿 | 10 髋 yaw、11 髋 roll、12 髋 pitch、13 膝、14 踝 |
| 左腿 | 20 髋 yaw、21 髋 roll、22 髋 pitch、23 膝、24 踝 |
| 头颈与嘴 | 30 脖 pitch、31 头 pitch、32 头 yaw、33 头 roll、34 嘴 |
| IMU to DXL | ID 200，协议和板卡类型按实际固件 |
| 串口 | 参考 HAT 使用 `/dev/ttyS2`，1,000,000 bps，8N1 |
| 设备数 | 15 颗舵机＋1 块总线 IMU，16 个地址 |
| 中位 | 本流程以 2048 为机械零位约定；不等于所有关节 HOME |

左右按鸭子自身方向定义。Dynamixel 与 Feetech 的 SDK、协议和寄存器不能互换使用。

## 参考 HAT 与 HD1910 针序

| 参考板/设备 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| HATz J13/J14 TTL | GND | +BATT | DATA | 无 |
| HATz J11/J3 RS485 | GND | +BATT | A | B |
| HD-1910-C001 AMP2.0-3P | DATA | VCC | GND | 无 |

因此参考 J13→HD1910 转接需按 **1→3、2→2、3→1** 对应。以两端各自引脚图确定编号，不把这个关系当成所有线束的物理左右顺序。IMU 接口另核其板卡资料。

瑞莎 USB-C 1 为 5 V 输入；GPIO 逻辑为 3.3 V。电池原压不能直接进入主控 5 V 或 GPIO 逻辑脚。

## 服务与端口

| 项 | 常见值 |
| --- | --- |
| Studio | `microduck-studio.service`，HTTP 8000 |
| 主程序 | `robotd.service`，本地 `/run/robotd.sock` |
| SSH | `ssh.service`，TCP 22；部分系统另有 ssh.socket |
| 视频服务 | `mediad.service`，扩展功能，首次动作验收不要求运行 |
| 视频信令 | 默认 8443，不是 Studio 主页 |
| 媒体独立控制台 | 部分版本 8080，不是 Studio 主页 |

## 文件位置要从服务实际参数确认

| 内容 | 本教程参考分支常见位置 |
| --- | --- |
| robotd 程序 | `/opt/robot/feetech-ft5-r5/robotd` |
| robotd 参数 | `/etc/robot/feetech-ft5/robotd.toml` |
| 舵机/IMU 标定 | `/etc/robot/feetech-ft5/hd1910-calibration.toml` |
| Studio 状态与导入模型 | `/var/lib/microduck-studio/` |
| Studio 日志 | 服务参数指定的日志目录，参考部署为 `/var/log/microduck-studio/` |
| 源码式 Studio | `/home/radxa/studio-dev/` |
| 较新发行式 Studio | `/opt/microduck/software/current/studio/` |
| 媒体默认配置 | 某些版本读取 `/etc/robot/robotd.toml`，与上面主程序参数文件不是同一路径 |

不因为某个路径“通常如此”就覆盖它。使用 `systemctl cat`、服务 `ExecStart` 和配套说明确认实际配置；备份同名 `.saved.toml` 等持久文件。

## 只读检查命令

```bash
systemctl status robotd.service microduck-studio.service --no-pager
systemctl cat robotd.service
sudo journalctl -u robotd.service -b -n 100 --no-pager
hostname -I
uptime
free -m
df -h /
cat /sys/class/thermal/thermal_zone*/temp
```

热区数值常以毫摄氏度显示，且不同热区代表不同部件；不要把所有值都叫同一个 CPU 温度。是否降频与是否异常以主板和运行时的实际状态判断。
