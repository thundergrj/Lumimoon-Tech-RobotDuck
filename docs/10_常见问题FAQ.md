# 08 · 常见问题 FAQ

按"现象"查。大多数问题集中在**总线通信**和**机械干涉**两类。

---

## 总线 / 舵机通信

**Q：整条总线一个舵机都扫不到。**
优先怀疑这几点，按顺序排：
1. **线序错**——这是最常见的。HD-1910 的 AMP2.0 是 **1 = 信号 / 2 = 电源 / 3 = 地**，和 Dynamixel / 部分飞特 HL 的 1=地/3=信号相反。核对 AMP2.0 转 5264 转接线两端（见 [04 §3](04_电子接线与舵机总线.md)），用万用表量通断。
2. 没供电，或 7.5V 适配器没插好。
3. 上位机选错串口、或串口驱动没装（CH340 / CP210x）。
4. 扫描用的波特率和舵机当前波特率不一致——换个波特率再扫。
5. （在主控上扫时）UART2 被系统的 `serial-getty` 占死，需要 mask 掉（见 [08 §3](08_主控系统与刷机.md)）。

**Q：能扫到一部分，少一两个。**
- 少的那个舵机线没串好 / 转接处接触不良，重插。
- 那个舵机波特率没统一到 1 Mbps——单独接出来，用它当前波特率扫到后改成 1 Mbps。
- 那个舵机 ID 和别的重复了（见下）。

**Q：怀疑有重复 ID。**
出厂 ID 相同，如果改 ID 时漏了一个或改重了，总线上就有冲突。把可疑舵机逐个单独接出来，确认 / 重设 ID（[05 §3](05_舵机调试_ID与中位校准.md)）。改 ID 必须一次只接一个。

**Q：改了波特率后那个舵机再也扫不到了。**
它现在跑在新波特率上。用新波特率（通常就是你改成的 1 Mbps）去扫，而不是出厂波特率。

**Q：某个舵机抖动 / 嗡嗡响 / 发烫。**
- 机械卡滞导致它一直堵转发力——断电，手动活动该关节找卡点（常见于踝干涉、壳体夹、轴承压歪）。
- 该关节中位没校准好，一直在跟一个够不到的目标较劲——重校中位。
- 供电掉压（电源太弱），多个舵机同时动时尤其明显——用配套 7.5V 适配器，别用劣质小电源。
- 确实坏了——点动单测，异常就更换。

## 机械 / 结构

**Q：鸭嘴开不了 / 开合很卡。**
典型问题。`jaw_soft` 和 `bottom_head_shell` 摩擦导致。用适配 HD-1910 的 v0.1 结构件（已缩短 `jaw_soft`）；自己打印偏紧的话，轻微打磨接触面直到顺畅（见 [02 §4](02_3D打印指南.md)）。

**Q：脚 / 踝转不动。**
- 底部和舵机干涉——确认用的是 v0.1 把踝内部改成圆弧的版本，不是早期 XL330 平底版本。
- 轴承压歪或装错位——重新从外侧压入 16×22×4 轴承，靠脚的限位卡扣锁住。

**Q：螺丝拧不进 / 拧爆了孔。**
- 用错长度（M2×5 / ×6 / ×8 / M2.5×6 别混）。
- 打印件孔小了或有溢料——先用合适钻头清孔再拧。
- 自攻螺丝拧打印件**手感到明显阻力就停**，别硬拧。

**Q：某颗螺丝柱位置拧不上（头部）。**
HD-1910 背面是凸起的，v0.1 对头部干涉的螺丝柱做了切角避让。确认用的是适配件；若自己打印，检查是不是用了旧版文件。

**Q：轴承松脱 / 晃。**
压轴承要垫平均匀用力。踝处靠卡扣 + `foot` 限位卡扣固定，确认卡扣到位。孔过大可用一点点轴承胶。

**Q：装完站不直、歪一边。**
某个关节装配时没对准中位。对照 [06 §3](06_通电自检与联调.md)：歪的方向能反推是哪个关节，回去重校那个关节的中位和装配角度。

## IMU / 摄像头 / 主控

**Q：主控上 `i2cdetect` 扫不到 IMU。**
- 接线：VCC/GND/SDA/SCL 四根有没有接对，供电是不是 **3.3V**（别接 5V）。
- 对应 I²C 总线在系统里有没有使能（设备树 / overlay）。
- SDA/SCL 接反——对调试试。

**Q：摄像头识别不到。**
- FPC 排线方向反了或没插到底——金手指朝触点，插到底扣紧。
- CSI overlay 没开。
- 走路阶段用不到摄像头，可先放后面。

**Q：主控扫舵机总线扫不到（命令行）。**
八成是 UART2 的 `serial-getty` 占着。mask 掉它再试（见 [08 §3](08_主控系统与刷机.md)）。

**Q：机器人一松手就倒。**
正常——目前还没有平衡 / 步态策略在跑。回中位只是让它摆出站姿，真正"自己站稳、会走"要软件 + RL 策略（见 [09 仿真、步态与强化学习](09_仿真步态与强化学习.md)）。调试阶段请扶着或架高。

## 供电 / 安全

**Q：一动起来主控 / 舵机就重启、掉压。**
电源带不动。用配套 7.5V 适配器给舵机、独立 5V PD 给主控，别共用劣质电源。

**Q：通电瞬间有焦味 / 冒烟。**
**立刻断电。** 几乎都是线序接反（电源 / 信号）或短路。重查 [04 接线](04_电子接线与舵机总线.md)，万用表量正负极和通断，确认无误再上电。

**Q：能用锂电池吗？**
桌面调试阶段**不建议**，用适配器更安全好查。整机集成阶段才上可拆 18650 电池组，并要处理充电 / 过放 / 舵机供电轨等问题。
