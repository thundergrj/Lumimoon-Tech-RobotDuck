# 03-装配与接线

## 1. 核对结构版本与打印件

逐步图来自仓库已有的 [HD1910 装配 PDF](../resources/HD1910%20开源资料/开源资料/xgoduck_hardware-master/Assembly_Guide.pdf)，共 25 页。其 Arduino Uno Q 电控固定方式不能直接作为 Radxa/HAT 安装图，应该参考B站视频的安装瑞莎RK3566 Zero 3W的安装方法。

原教程 `upper_leg`、`trunk_base` 与资料包 `thigh`、`body` 等命名不同，先核对版本和实际位置，不能混装。

自行打印时使用同一结构版本的完整文件与切片参数，先打印舵机位和轴承位试配，再打印整套。检查缺层、裂纹、翘曲与毛刺；承力方向、壁厚、材料按结构要求，脚底使用对应柔性材料。不要靠颜色判断左右件。

轴承压正，自攻螺丝拧至贴合，按孔位选择长度，不强行锁紧或顶到舵机壳、线材。

## 8. 安装瑞莎、HAT、IMU 与电池

按本套件电控支架安装，不照搬原图 Arduino 板位。

### 8.1 对照板卡安装 PDF

[《Microduck接线与板卡安装说明》](Microduck接线与板卡安装说明.pdf)共 9 页，可按下表查阅：

| PDF 页码 | 内容 | 装配时重点检查 |
| --- | --- | --- |
| 第 1 页 | 板卡清单与版本区别 | 瑞莎、HAT、IMU、分线板及桌面调试板各自用途 |
| 第 2–6 页 | 板卡与接口说明 | 接口位置、供电与总线区别、分线板及电池触点板 |
| 第 6–7 页 | 瑞莎与 HAT 安装 | 叠装层次、40 针对齐、板间支撑及插拔空间 |
| 第 7–8 页 | 电池触点板与分线板安装 | 触点朝向、板件固定、焊点绝缘和电源线减力 |
| 第 8–9 页 | IMU 安装 | 刚性平台、接口朝外、线束固定及朝向记录 |

附件中绿色 **ASE01187-D1** 的接口定义与黑色 **HUMERDUCK** 的安装照片需要区分：安装位置可参考照片，针序必须核对手中板卡的实际版本。当前 PDF 正文止于第 3.3 节，文中提到的后续第 4–6 节未包含在此附件内；接线和通电检查请使用本章第 9 节。

### 8.2 固定瑞莎与 HAT

1. 按“侧壳 → 绝缘支撑／隔柱 → 瑞莎 → 板间支撑与 40 针连接 → HAT”的层次试装，HAT 元件面朝外。
2. 先确认主控的 USB-C、HDMI、microSD 和排线座有使用空间，再固定瑞莎。散热器周围留空，金属件不碰焊点。
3. 按两块板的丝印和布局确认物理 1 脚，将 40 针完整对齐，不反插、不偏排、不错一列。
4. 用匹配隔柱支撑 HAT，让两块 PCB 平行；不靠排针独自承受板卡和线束拉力。拧螺丝时若 PCB 弯曲，先检查隔柱高度。
5. 暂不合壳，保留排针与总线接口的检查空间。

### 8.3 固定分线板、电池触点板与电池支架

使用附件中的 `dxl_hub` 与 `banana_pcb` 方案时：

1. 将电池触点板固定在后部配套支架中，触点朝向电池接触侧，电源线引向机身内部；此时不插电池。
2. 将分线板固定在躯干舵机附近，接口朝可插拔的一侧，与舵盘和连杆活动区域分开。
3. 检查焊点与裸铜绝缘，在固定结构上为电源线减力，避免电池插拔时拉扯焊点或夹线。
4. 电池位置与质量应匹配模型，支架固定牢靠，开关和插头可接近。实际极性核对完成后，才按本章第 9 节进入供电检查。

使用其他配电方案时，按对应板卡和支架说明安装，不因参考图出现分线板就临时改变已经确认的供电路径。

### 8.4 固定 IMU 与预留扩展位置

1. 参考 PDF 第 9 页，在躯干舵机下方的配套固定平台安装 IMU，接口朝外并保留插拔空间。
2. 使用匹配定位件、压片或隔柱固定，避免压住芯片、插座和电容，板底焊点与金属结构隔开。
3. 轻推板件检查刚性，IMU 与躯干之间不应相对移动。不要放在活动头部或靠软线、软泡棉悬吊。
4. 在附近固定结构上固定线束，插头旁留自然弯；记录板面、接口朝向和机器人前进方向，固定后再标定。
5. 摄像头只预留位置和排线路径，首次动作调试可不接。安装时断电，以触点位置判断 FPC 朝向，不统一写成“金手指朝上/朝下”。

### 8.5 对照舵机接线拓扑图预留线束

![Microduck 舵机接线拓扑图：右腿 10–14、左腿 20–24、头颈与嘴 30–34、IMU 200](舵机接线拓扑图.jpg)

[打开原图查看细节](舵机接线拓扑图.jpg)。图中的左右以鸭子自身为准，与第 02 章编号表一致。

| 分支 | 图中连接关系 | 装配时的走线重点 |
| --- | --- | --- |
| 右腿 | 分线板 → 10 → 11 → 12 → 13 → 14 | 髋、膝和踝活动处留余量，合腿壳前先穿线 |
| 左腿 | 分线板 → 20 → 21 → 22 → 23 → 24 | 对照左侧结构布线，不因镜像装配接错标签 |
| 头颈与嘴 | 分线板 → 30 → 31 → HAT → 32 → 33 → 34 | 预留脖子俯仰、转头与侧倾所需的线长 |
| IMU | 分线板 → 200 | 单独引线到刚性安装位置，不用 IMU 接口为整腿转供电 |
| 电源 | 电池 → 电池触点板 → 分线板 | 核对实际板卡定义，线材固定且不受活动件挤压 |

这里的箭头表示图中的线束连接顺序，不代表信号单向传输，也不代表各舵机在电气上串联分压。拓扑图用于安排连接关系，不能代替插头针序图；HAT 转接线仍需按 DATA、VCC／+BATT、GND 逐根核对。

**图内参数的使用范围：**电池旁的 `7.2 V / 8.2 V`、`3–5 A` 和膝关节的 `homing_offset -512` 是原图标注，不作为本套件通用的电池额定值、供电选型或标定写入值。电池参数按实物及第 01 章及本章第 9 节核对；膝关节偏移按第 06 章实机标定，不照图直接写入。分线板口数和 HAT 接口名称同样以实际 PCB 为准。

合壳前拍板卡、IMU 朝向和走线照片。移动电池、更换结构或重新固定 IMU 后复查相关标定。

## 9. 接线与上电前检查

所有插拔、改针序和通断测量都在电池、外部电源及 USB 断开后进行。按第 8.5 节拓扑安排线束，逐段核对，不以插头能插入或线色相同作为接线正确的依据。

### 9.1 分清主控与整机供电

| 场景 | 接法 | 检查点 |
| --- | --- | --- |
| 仅配置瑞莎系统 | 合规 5 V 电源接主控 USB-C 1，舵机电池断开 | 不把电池原压送入 USB-C 或主控 5 V 脚 |
| 整机调试 | 按配套电池触点板、分线板及总线电源路径接入电池，匹配 HAT 降压后给瑞莎供 5 V | 核对当前 PCB 的供电路径、极性、开关、保护件与负载能力 |

不默认允许 HAT 供电与主控 USB-C 电源同时并接。2S 锂电常见标称 7.4 V、满电 8.4 V；整机允许电压还受 HAT、IMU、分线板及连接器限制，不能只看舵机额定范围。电源与线束按[本套 BOM](../bom/BOM-ZERO3W-HD-1910-C001-HAT.md)和实际负载核对，5 V 电源的额定电流较大也不能代替匹配的舵机电源。

### 9.2 核对参考 HAT 与转接线

以下针序仅适用于已核对的参考 HAT 版本。黑色 HUMERDUCK 或其他 PCB 必须先核对本板定义，不能照外观套用。

![参考 HAT 布局与 1 脚位置](../assets/hat_board_layout.png)

| 接口 | 类型与定义 | 使用范围 |
| --- | --- | --- |
| J13 / J14 | 3 针 TTL：1 GND、2 +BATT、3 DATA | 经匹配转接线连接飞特总线 |
| J11 / J3 | 4 针 RS485：1 GND、2 +BATT、3 A、4 B | 不将 A/B 接到 TTL 舵机；本章分线板供电方案不使用该口接电池 |
| J4 | 40 针主控接口 | 按物理 1 脚对齐瑞莎，传递电源、地和控制信号 |

C001 的 AMP2.0-3P 接口定义为 **1 DATA、2 VCC、3 GND**，与参考 HAT 的 1、3 脚定义相反：

| 参考 HAT J13 | HD1910 端 | 电气连接 |
| --- | --- | --- |
| 1：GND | 3：GND | 地接地 |
| 2：+BATT | 2：VCC | 电源相连 |
| 3：DATA | 1：DATA | 数据相连 |

按两端各自连接器的看图方向识别针号。这个转换是 DATA 与 GND 的对应位置交换，不是电源正负反接，也不是把插头硬倒插。

断电后用万用表逐根检查转接线：GND 到 GND、VCC 到 VCC、DATA 到 DATA，三根线之间无短路。项目曾因 DATA/GND 对应错误出现通信帧错误，因此先检查转接线，再接入设备。

### 9.3 逐段连接舵机、IMU 与主控

1. 保持断电，从一颗已编号舵机开始核对线序，再按腿、头颈等模块逐段连接。每次改变接线前都断电，接头保持可检查。
2. 对照 ID 标签核对设备身份；总线按 ID 寻址，不按插线先后分配身份。双口舵机提供进出连接，不能把一个空口强接多条线。
3. IMU 作为独立支路或链末端接入，核对板型、针序、供电范围及 ID 200，不让腿部电流穿过未经核验的 IMU 过线接口。
4. “IMU to DXL”名称不能代替协议核对。实际使用独立 I²C 模组时，改按[独立 IMU 附录](附录/独立I2C-IMU方案.md)操作。
5. 确认瑞莎与 HAT 的 40 针无错位。GPIO 逻辑为 3.3 V，普通 UART TX/RX 不能直接并接三线舵机 DATA，必须经过匹配的半双工收发电路。
6. 参考运行时使用 `/dev/ttyS2`、1 Mbps，UART2 的系统与引导控制台占用按[第 04 章](04-烧录系统.md)处理。不让另一块 USB 调试板同时向该总线发送命令。

摄像头排线只在彻底断电后插拔，核对触点、插入深度及锁扣。首次检查不启用媒体服务；扩展验证见[摄像头附录](附录/摄像头扩展与网络恢复.md)。

### 9.4 分段上电检查

先完成下列检查，再分段上电：

- [ ] 电池正负、HAT 输入和降压后的 5 V 输出路径已按本版确认。
- [ ] 转接线通断及针序已核验，无裸铜搭接或短路。
- [ ] 所有板卡、线材及连接器允许电压与电池满电电压相容。
- [ ] 未并接两路未经确认可并联的主控电源。
- [ ] IMU 下游没有未经核验的大电流负载。
- [ ] 开关和插头可接近，线束固定且无夹线。

首次供电先确认主控与 HAT 的实际电压，再断电接入后续模块、重新检查。按已核定供电路径操作，不临时改变接头极性或绕过保护件。出现异常温升、气味或电压异常立即断电，查明后再试。舵机扫描与连续回读在第 05 章完成，此时不发送运动命令。

## 10. 本章验收

- [ ] ID 与关节对应，32 yaw、33 roll 已核对。
- [ ] 轴承、舵盘、支撑、紧固件无松动，关节无干涉。
- [ ] 左右脚和 TPU 前后方向正确。
- [ ] 线束有余量，合壳不夹线，接口可接近。
- [ ] 板卡绝缘、散热空间、IMU 刚性固定、电池固定均已检查。
- [ ] 接线、极性与分段供电检查完成，异常已处理。
- [ ] 检查后已断电，准备烧录或核对系统。
