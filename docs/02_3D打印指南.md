# 02 · 3D 打印指南

> 本章面向**散件用户**，或想自己补打、换色、换材料的用户。成品 / 半成品套件的打印件已经做好，可跳过本章，直接去 [03 机械装配](03_机械装配.md) 或 [04 接线](04_电子接线与舵机总线.md)。

机器鸭的整个机体几乎都是 FDM 3D 打印件。整套结构经过针对 **HD-1910 舵机**的适配与优化（当前结构版本 v0.1），和早期基于 XL330 舵机的版本有明显区别——照搬旧文件会装不上。本章说明打什么、用什么料、怎么打、以及这些结构为什么要这样改。

## 2. 材料选择

| 部位 | 推荐材料 | 原因 |
| --- | --- | --- |
| 绝大部分结构件 | **PLA**（或 PLA+） | 刚性好、尺寸稳定、好打、便宜。机器鸭不到 1 kg，PLA 的强度足够 |
| 脚底 `sole_left` / `sole_right` | **TPU 95A** | 软质，增加地面摩擦和落地缓冲，走路更稳、更安静 |
| 软下巴 `jaw_soft` / 软嘴 `soft_mouth_top`（可选） | TPU 或软 PLA | 需要一点弹性来贴合开合 |

> 不建议用 ABS：收缩大、易翘边，这套件尺寸精度要求偏高，ABS 容易导致孔位对不上。PETG 可用但更黏、支撑难拆，新手优先 PLA。

## 3. 打印参数建议

下面是一组稳妥的通用参数，具体以你的机型和耗材微调：

| 参数 | PLA 结构件 | TPU 脚底 |
| --- | --- | --- |
| 层高 | 0.16–0.20 mm | 0.20 mm |
| 壁厚（外壁圈数） | ≥ 3 圈 | 3 圈 |
| 填充 | 25–40%（承重件偏高） | 15–25% |
| 填充图案 | 网格 / 陀螺（Gyroid） | 网格 |
| 顶 / 底层 | 4–5 层 | 4 层 |
| 打印速度 | 40–60 mm/s | **20–30 mm/s**（TPU 要慢） |
| 支撑 | 按件判断，优先"仅接触平台" | 尽量规避 |
| 喷嘴温度 | 200–215 ℃（PLA） | 220–235 ℃（TPU） |
| 热床 | 55–60 ℃ | 40–50 ℃ |

**摆放与支撑要点**：

- 关节孔、轴承位尽量**竖直朝上或水平**摆放，避免跨在支撑上导致圆孔变形（轴承压不进或过松）。
- 带舵机安装耳的件，优先让安装面贴平台打印，保证螺丝孔平整。
- 打完后用"通孔检查"：拿对应螺丝 / 轴承试插每个孔，有缝隙溢料或孔小了的，先用合适钻头 / 铰刀清一下，别硬怼。

## 4. 这套结构为什么这么设计（选读，但很有用）

这套结构是在原 MicroDuck（基于 Dynamixel XL330 舵机）基础上，为 **HD-1910 舵机**重新适配并优化出来的。了解这些改动，装配时会少踩坑：

**根因：舵机背面形状不同。** XL330 拆掉副舵盘后背面是**凹**的，HD-1910 是**凸**的。机体里大量结构变化都由这一点引起——凸起的背面会跟原来的螺丝柱、腔体打架。

几处关键优化：

- **头部**：HD-1910 的凸起会和后方螺丝柱干涉。做法是把螺丝柱切掉一部分消除干涉，同时不影响螺丝正常安装。
- **下巴**：受 3D 打印精度影响，`jaw_soft` 会和 `bottom_head_shell` 摩擦，导致**开嘴困难甚至开不了嘴**。优化把 `jaw_soft` 缩短，消除摩擦。装的时候如果发现嘴卡，先往这个方向查。
- **脖子**：原版脖子连接件只有 1 mm 厚，3D 打印风险高（易断）。已加厚。
- **躯干 `trunk_base`**：原版薄、每个舵机只有 2 个孔固定，较脆。优化为：加厚底座、**每个舵机 3 个孔固定**、`power_support` 改为以舵机为基准固定、并把陀螺仪固定孔改成兼容 LSM6DSX 系列（也就是你套件里的 LSM6DSV16X）。
- **胯部**：原版 yaw 用两个零件夹住舵机，打印后稳定性差、且和 HD-1910 不兼容，螺丝孔位还挡住 `trunk_base` 前方舵机的螺丝。优化改成**一体式 yaw**，结构更简单稳固，并给前方舵机让出拧螺丝的空间。
- **大腿 `upper_leg`**：加厚加强板 `upper_leg_rigidity_plate`；去掉两个定位柱以兼容 HD-1910，顺带让走线更顺、更好装。
- **脚 `ankle`**：原版轴承从内部装、底部是平的，会和舵机干涉导致脚转不动，而且除非件很软否则很难装上腿。优化为：内部改圆弧让脚能顺畅转动；增加一处"弹筋"结构，既方便把踝装上腿部模组，又能从外侧更好地压入轴承，还靠脚上的限位卡扣大幅降低轴承松脱风险。

> 一句话：**如果你是自己打印，务必用适配 HD-1910 的 v0.1 结构文件，不要用早期 XL330 版本。** 否则舵机背面凸起会让你各种装不上。
