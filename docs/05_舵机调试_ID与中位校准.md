# 05 · 舵机调试：ID 与中位校准

这一章把 15 个"长得一样"的舵机，变成总线上各有身份、零点统一的 15 个关节。**这是整个项目最关键、也最容易被忽略的一步。** 做扎实了，后面联调和跑步态才顺。

为什么必须做：

- 15 个舵机挂在同一条总线上，**靠 ID 区分**。出厂 ID 通常都是同一个（如 1），不改 ID 根本没法分别控制。
- 总线通信要**统一波特率**。控制环按 **1 Mbps** 设计，出厂若不是这个值要改过来。
- 每个关节要有统一的"**中位（零点）**"。装配时让所有关节停在零位，机器人的姿态才和软件里的模型对得上。

---

## 1. 工具：舵机控制板 + 上位机软件

- **硬件**：套件里的微雪总线舵机驱动板，一头 Type-C 连电脑，一头经 AMP2.0 转 5264 接舵机；7.5V 适配器给舵机供电。
- **软件**：HD-1910 是飞特协议的 TTL 总线舵机，用**飞特舵机调试上位机**（常见名 `FD.exe` / Fo / SCServo Debug，或微雪提供的配套调试软件）。在 Windows 上安装对应串口驱动（CH340 / CP210x 之类，看板子用的芯片）。

> 上位机的界面各版本略有差别，但核心功能都一样：**扫描、改 ID、改波特率、读写位置**。下面讲的是通用流程，按你装的软件对应操作即可。

---

## 2. 关键前提：一次只接一个舵机改 ID

因为所有舵机出厂 ID 相同，如果一次把 15 个都接上去改 ID，总线上会有一堆相同 ID 在抢答，改不动也分不清。所以改 ID 阶段：

> **一次只接一个舵机**，改好它的 ID，拔下，换下一个。15 个逐个过。

## 3. 逐个写入 ID

对每一个舵机重复下面的步骤：

1. 只接这一个舵机，控制板连电脑、通 7.5V 电。
2. 打开上位机，选对串口，波特率先用舵机**当前**的波特率扫描（出厂常见 1 Mbps 或 115200；扫不到就换个波特率再扫）。
3. 扫到后，它会显示当前 ID。按 [11 速查](11_接口与参数速查.md) 的规划，把 ID 改成这个舵机对应部位的编号。
4. 写入 ID，断电重连确认改成功。
5. 拿记号笔 / 贴纸在舵机上标好"ID + 部位"，拔下，换下一个。

ID 规划（务必按这个来，后续软件直接套用）：

| 部位 | ID | 部位 | ID |
| --- | --- | --- | --- |
| 右髋 yaw | 10 | 左髋 yaw | 20 |
| 右髋 roll | 11 | 左髋 roll | 21 |
| 右髋 pitch | 12 | 左髋 pitch | 22 |
| 右膝 | 13 | 左膝 | 23 |
| 右踝 | 14 | 左踝 | 24 |
| 脖 pitch | 30 | 头 yaw | 32 |
| 头 pitch | 31 | 头 roll | 33 |
| 鸭嘴 | 34 | | |

> 建议按一个固定顺序过（比如先右腿 10–14、再左腿 20–24、再头颈 30–34），边改边在清单上打勾，15 个不重不漏。

---

## 4. 统一波特率到 1 Mbps

控制环按 1 Mbps 设计。改 ID 的同时（或之后），把每个舵机的波特率设为 **1 000 000 bps（1 Mbps）**：

- 在上位机里找到波特率寄存器，设为 1 Mbps 对应的值，写入 EEPROM。
- 全部统一后，之后扫描 / 控制都用 1 Mbps。
- **注意**：如果你把某个舵机波特率改了却没记住，下次会"扫不到"它——先用它当前波特率扫到，再改。

> 为什么是 1 Mbps：50 Hz 控制环每拍要和 15 个舵机 + IMU 来回通信，1 Mbps 是官方算过能跑满这个节拍的速率。把舵机丢在 115200 上，控制环会直接塌。

---

## 5. 中位（零点）校准

"中位"就是每个关节的参考零位。12 位磁编码舵机的位置范围是 0–4095，中位通常对应 **2048** 一带。校准的目标是：**装配时让每个关节停在零位，使机器人呈标准站姿**。

做法（两种，按你软件支持的来）：

- **软件设中位**：在上位机把舵机转到机械零位后，用"设为中位 / 校正零点"功能，把当前位置标定为中点。
- **转到中点再装**：把舵机位置写到 2048（或该型号的中位值），让输出轴停在中位，再按这个姿态装配。

实操建议：

1. 结合 [03 机械装配](03_机械装配.md)：**装之前**把每个舵机转到中位。
2. 腿部关节的零位，对应机器人**自然直立、双脚平行着地**的姿态；头颈零位对应**正视前方**；鸭嘴零位对应**闭合**。
3. 装完后整机上电，所有关节回中位，机器人应能**对称地站直**。如果某条腿歪、或脚不平，多半是那个关节装配时没对准零位——回到该关节重新对中。

> 📷 *待补拍：全部回中位后机器鸭对称站立*

## 6. 单个点动测试

每个舵机 ID / 波特率 / 中位都设好后，逐个做个点动测试，确认它"听话"：

- 在上位机给某个 ID 发一个小角度目标（比如中位 ±100），看它是否平滑转到位、能读回位置。
- 顺便留意：有没有异响、过热、抖动、堵转报警。有问题的舵机现在换，比装进机体后再发现省事得多。

> HD-1910 支持读回位置 / 速度 / 电流 / 电压 / 温度 / 负载。点动时如果能看到这些反馈在变，说明这颗舵机通信、编码、驱动都正常。
