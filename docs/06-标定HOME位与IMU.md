# 06-标定 HOME 位与 IMU

[返回首页](../README.md) · 上一章：[配置 Studio](05-配置Microduck-Studio.md) · 下一章：[功能测试](07-测试站立坐下与走路.md)

**目标：**让机械零位、关节方向、模型 HOME 与 IMU 安装方向一致，并确认结果写入后可持久读回。

开始条件：15 颗舵机和 IMU 持续有新鲜回读；机体可托稳；尚未运行策略；已确认模型与硬件匹配。总线还会掉 ID、主程序没回话时先排障，不能用标定掩盖通信问题。

## 1. 正确顺序

```text
整机机械零位复核 → 舵机中位与方向
→ 交还总线 → IMU 安装方向粗校与验证
→ 卸力 → 写进主程序并读回 → HOME 保持检查
→ 必要时站姿精校 → 再卸力保存、读回、重启复查
```

“标 HOME”包含了多个不同工作，不能只点一次“全部校准”就视为完成。

| 要核对的量 | 含义 | 不能混淆的事 |
| --- | --- | --- |
| 舵机中位/零偏 | 当前物理机械零位对应 2048 | 不把 HOME 曲腿姿态都设成 2048 |
| 关节方向 | 编码读数变化如何映射为模型正负角 | 左右镜像不代表两边设置必然相同 |
| HOME | 当前模型要求的准备角度 | 不从“站着看起来顺眼”猜角度 |
| IMU 安装方向与偏置 | 传感器坐标转换到躯干坐标、静止偏置 | 不只校一个水平倾角就忽略轴向与符号 |

## 2. 复核机械零位，再做中位校准

1. 托稳整机，点“卸力”，等全部舵机确认卸力。
2. 进入“舵机”页，通过 Studio 接管总线。
3. 显示 Studio 的“零位”参考图。按该图摆放腿、脚板、头颈和嘴；本参考版说明为腿伸直、头摆正、嘴闭合，脚板朝向严格对照 3D 图。
4. 先选择一颗关节，确认 ID 对应实物，打开“中位校准”预览。
5. 看预览中的当前值与预计偏差。大幅偏差先查装配、错齿、ID 与方向，不直接确认。
6. 确认后校准该颗，观察其真实位置与读回。此参考版本校准完成后会保持该关节，后续手工摆动前先卸力。
7. 按固定顺序完成其余关节，保存前后记录。全部已按图摆好且确认正确后，才使用一键校准。

**校准过程中不要强扳正在保持的关节。** 原始偏移或上次备份应保留，以便确认错误时撤销；不要无记录地连续重标。

本套 Studio 将舵机内部当前机械零位设为 2048，主程序侧再使用相应的零位约定。不能同时叠加另一份来源不明的旧软件零偏，否则会形成双重补偿。

## 3. 核对每个关节的方向

在支撑和小范围条件下，逐颗检查目标正向小角度对应的实际运动方向，并与 Studio 3D、模型关节定义一致。

重点检查：

- 左腿 20–24 与右腿 10–14 是否对应正确。
- 32 是否真的控制头 yaw，33 是否真的控制头 roll。
- 髋 pitch、膝、踝三者是否按模型的正负方向变化。
- 头部、嘴的闭合端是否在机械允许范围内。

修改的是当前校准流程中的方向参数；不要为修正显示随意改舵机硬件相位、接电源反向或扩大限位。完成后托稳、确认卸力，点“交还主程序”，等待真实状态恢复。

## 4. IMU 标定前先固定机体与传感器

IMU 与躯干之间必须没有相对活动。标定动作移动的是**整个躯干**，不是只低头、只动脖子，也不是单独晃 IMU 板。

本参考软件的躯干坐标为 X 向前、Y 向左、Z 向上。正常站姿下的投影重力通常接近 `[0,0,-1]`；原始加速度计静止时读的是比力，朝向符号可能不同，不能把二者当成同一个量。

若页面显示物理单位，静止加速度模长应接近 1 g，使用 m/s² 时约为 9.81；角速度应接近静止偏置。数据冻结、反复陈旧或明显不合理时先排查，不采集标定。

## 5. IMU 安装方向粗校

1. 进入“IMU”页，核对实际来源、ID/协议与硬件类型。
2. 新机按“IMU 安装方向”向导操作；已有结果需重做时使用该版本提供的“重新标定方向”，不要直接修改四元数字段。
3. 保持卸力，用支架或双手托住整机，使躯干处于参考直立姿态。
4. 按页面要求静止采集，参考版本约 3 秒；采集期间机体和 IMU 均不晃动。
5. 把整个躯干缓慢向前倾斜约 15–30°，按向导采集前倾姿态，参考版本约 3 秒。
6. 计算后，先把躯干回正、静止，再点“交给主程序验证”，按提示再次做需要的倾斜动作。
7. 查看当前板卡身份、协议、方向和验证结果；只有主程序验证通过才继续。

采数时数据来源、板卡类型或协议变了，原采集不能继续使用。不要通过“跳过”把未验证的方向标成完成。

## 6. 写进主程序并退出出厂标定模式

**先扶稳并卸力，等读回确认。** 写标定通常涉及重启主程序，站着时执行可能让机体失去支撑。

1. 回到“上手清单”，核对舵机中位、15 颗方向和 IMU 验证结果齐全。
2. 点击“写进主程序”，阅读预览或确认说明。
3. 等待备份、写入、重启及运行端逐项读回结束，不刷新连点。
4. 确认页面已离开出厂 `commissioning`，进入 `motion`，主程序处于可提供实时回读的正常阶段。
5. 确认 15 颗已标定、限位与方向正确，IMU 安装方向验证有效，且仍处于卸力状态。

退出标定模式使用配套向导完成，**不手动删除不认识的 systemd drop-in 或修改 `calibration_complete` 来绕过检查**。存在外来启动参数、写入回滚或读回不一致时，保留诊断包交维护人员处理。

## 7. 检查 HOME，必要时做站姿精校

HOME 来自当前模型/运行时合同，可能包含髋、踝和头颈的非零角度。使用配套 HOME，不照抄其他机体或 Observer 模型的角度与滤波。

1. 把机器放在平整防滑地面，人员托稳躯干，保护绳保持松弛。
2. 确认没有行走策略和速度命令，再按当前版本的“站姿使能/站起来”流程进入 HOME 保持。
3. 观察实际两脚接地、左右对称、头颈朝向与参考图，检查关节反馈能跟上目标，没有卡死、顶限位或持续抖动。
4. 若能站稳但水平有小偏差，按 IMU 页“站着校准”的提示采数。此操作不能用来补偿装错的关节或歪斜的传感器支架。
5. 需要写进主程序或切模式时，先失能、托稳并确认卸力，再按向导保存与读回。

参考版出厂标定模式有受控的 `hold-home` 能力，并非所有版本都支持。没有相应入口或提示不允许时，先完成卸力状态的粗校与正式写入；不要直接调用未知运动命令。

## 8. 持久保存与重启复查

保存标定文件、模型身份、服务启动参数和对应记录。通过页面确认卸力后正常关机，再上电，复查标定没有丢、模式正确、15 颗和 IMU 仍正常回读。**重启后不自动开始走。**

拆装 IMU、修改舵机偏移、换舵机、交换 ID、移动电池或更换模型后，要复查相关内容；不能认为以前做过一次就永久有效。

## 9. 本章验收

- [ ] 机械零位、中位、关节方向、HOME 已区分并核对。
- [ ] 15 颗标定与限位读回一致，不靠手写完成标志绕过检查。
- [ ] IMU 静止/前倾采集和主程序验证通过，实际方向正确。
- [ ] 写进主程序成功，进入运动模式，状态持续更新。
- [ ] HOME 实物与配套合同一致，必要精校已持久保存。
- [ ] 重启后结果仍有效，机器当前已卸力。
