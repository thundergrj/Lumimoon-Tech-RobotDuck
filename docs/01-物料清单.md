# 01-物料清单

[返回首页](../README.md) · 下一章：[舵机编号与校准](02-舵机编号与校准.md)

**目标：**清点一套型号明确、可装配、可供电、可维护的 Microduck。关键配件缺失时，先补齐，不进入上电步骤。

本套 BOM 已指定 **瑞莎 Radxa ZERO 3W、飞特 HD-1910-C001 和配套 HAT**，并沿用 IMU to DXL（ID 200）方案。完整采购、装箱清单与 C001 参数见[本套硬件 BOM](../bom/BOM-ZERO3W-HD-1910-C001-HAT.md)。本章是开箱快查表；HAT 具体型号/PCB 修订号、电源额定值和结构数量仍需按实物登记。

## 1. 主线硬件

| 物料 | 数量 | 规格与核对点 |
| --- | --- | --- |
| 飞特 **HD-1910-C001** TTL 总线舵机 | **15 颗** | 型号已指定，逐颗记录固件和 ID；左右腿各 5，头颈 4，嘴 1 |
| 匹配 HD-1910-C001 的打印件 | 1 套 | 承力件、左右脚、头颈支架、嘴、电池固定件齐全，记录结构版本 |
| 柔性脚底 | 左右各 1 | 形状与脚壳一致，贴合牢固，不翘边 |
| 轴承、螺丝、舵盘与副轴附件 | 1 套 | 按本批次结构 BOM 清点，不合并不同结构版本的五金表 |
| 瑞莎 **Radxa ZERO 3W** | 1 块 | 主控已指定，登记内存、eMMC 有无、GPIO 排针；不直接替换为 ZERO 3E |
| **配套 HAT** | 1 块 | HAT 方案已指定，登记具体型号/PCB 版本、TTL 针序、输入范围、5 V 输出能力 |
| IMU to DXL 总线板 | 1 块 | 核对供应商、固件、针序、协议；本教程约定地址为 200 |
| 2S 电池与匹配充电器 | 各 1 | 常见标称 7.4 V、满电 8.4 V，输出能力与套件匹配 |
| 电源开关、保护件、电池连接线 | 1 套 | 与线材及连接器额定电流配套，核对极性和固定方式 |
| 舵机线、HAT 转接线、IMU 线 | 按布线表分项 | 三类分别清点，不因有 15 根舵机线就认为转接线齐全；核对 C001 与 HAT 的 DATA/GND 转换 |
| microSD 卡与读卡器 | 各 1 | 容量满足镜像要求，无 eMMC 时作为系统盘 |
| 散热器、绝缘间隔和板卡固定件 | 1 套 | 不碰排针、焊点，外壳内留散热空间 |

舵机总计 **15** 颗。加上 IMU 板，总线上应有 **16 个不同地址的设备**；IMU 不是第 16 颗舵机。

## 2. 调试工具

| 工具 | 用途 |
| --- | --- |
| 一台电脑 | 舵机编号、烧卡、浏览 Studio、保存记录 |
| 支持飞特协议的 USB 半双工 TTL 调试板 | 装配前逐颗编号和点动；普通 USB-UART 不能直接代替三线舵机接口 |
| 匹配的舵机调试电源 | USB 数据线通常不能承担舵机供电，须核对电压、极性与输出能力 |
| 万用表 | 断电查通断，上电量实际电压 |
| 螺丝刀、镊子、标签纸 | 区分五金、标 ID、理线 |
| 扎带、绝缘垫、热缩管 | 固线、应力释放、防短路 |
| Micro HDMI 线、显示器、键盘 | 首次配网与网络失联时恢复主控，建议装机时备好 |
| 机体支架或松弛保护绳 | 首次标定和动作测试时保护机体，不妨碍关节运动 |

**电池不能直接接入瑞莎的 USB-C 或 5 V GPIO。** 电池经已确认的 HAT 降压给主控供电；单独调试瑞莎时使用合规 5 V USB-C 电源，具体见第 03 章。

## 3. 扩展件最后启用

- IMX219 摄像头与匹配 FPC：核对两端针数、间距、触点方向。具体分辨率和视场以模组、镜头与驱动为准，不沿用旧教程“500 万像素”的描述。
- 蓝牙手柄：网页基本控制通过后再配对。
- 麦克风、扬声器、ToF：按选配模块说明安装，Studio 有入口不代表硬件已就绪。

摄像头不是基础站立和行走的前置条件。IMU 是平衡控制的重要输入，不能在未核验兼容性的情况下跳过它直接试走。

## 4. 随货文件也要清点

发货方应提供以下文件或固定版本链接，并填入[装机记录](附录/装机与验收记录.md)：

1. 本批次 BOM、装配图、螺丝规格表、打印文件。
2. HAT、IMU 和转接线引脚图，包含看图方向和 PCB 版本。
3. 指定镜像、SHA256 文件、烧录说明、登录方式。
4. 匹配的 Studio、robotd、小助手版本及串口配置。
5. 对应结构与舵机的模型部署包、用途与使用许可。
6. 机械零位图、HOME 参考姿态、方向与限位表。

缺少可核验镜像或模型包时，可以做硬件准备，但不进入行走验收。不用任意下载的 ONNX 填补缺件。

## 5. 本仓库参考资料的范围

[HD1910 资料包](../resources/HD1910%20开源资料/)包含本套选用的 **HD-1910-C001** 厂家规格书、协议、控制表、装配 PDF 和旧 BOM。以本次新增的 ZERO 3W＋C001＋HAT BOM 为电控清单；其中旧 `xgoduck_hardware-master/bom.xlsx` 使用 **Arduino Uno Q**，只引用明确匹配的机械参考项，不作为当前电控采购清单。

该结构 BOM 的轴承参考量为 10×15×3 mm 两个、16×22×4 mm 十一个；旧教程另一套结构写过三个小轴承。以当前结构的发货单和装配图为准，不把两者数量相加。旧文“打印件共 36 件”与颜色分项合计也不一致，本版不继续使用该总数。

C001 规格书在 7.4 V 下给出的额定电流为 0.9 A、堵转电流为 2 A；这两个值与空载电流不同。HAT、线束和保护件须按整机动作负载与峰值核验，不继续用旧文“每颗 0.5 A”推算整腿可过线电流。详细参数及用途区分见完整 BOM。
