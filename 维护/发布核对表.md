## 1. 冻结发货组合

当前物料依据：[ZERO 3W＋HD-1910-C001＋HAT BOM](../bom/BOM-ZERO3W-HD-1910-C001-HAT.md)。用户已确认主控、舵机完整型号和 HAT 方案；表中的未完成项不再包含这两个已指定型号本身。

| 项 | 当前状态 | 发布要求 |
| --- | --- | --- |
| 主控 | 已指定 Radxa ZERO 3W | 登记内存、eMMC/SD、PCB 与镜像适配，不直接替换其他主控 |
| 舵机型号 | 已指定 HD-1910-C001，15 颗 | 使用 C001 规格书，逐颗记录实际固件与配套调试软件，不再用旧文 C018 作为采购项 |
| 打印件与五金 BOM | 待核定 | 选择唯一结构版本，消除 2/3 个小轴承和打印件总数矛盾 |
| HAT PCB 与配电额定值 | 已指定 HAT 方案，具体型号/PCB 仍待核对 | 确认是否沿用现有 J13/J14 TTL、J11/J3 参考板，发布额定值、保护件与线束图 |
| IMU 板型/固件/协议 | 待核定 | ID 200、接口定义、单位、位置和刚性固定方式 |
| 系统镜像 | 待核定 | 可交付用途、固定下载入口、文件名、SHA256、首次登录和恢复方式 |
| robotd / Studio / helper | 待核定 | 指定匹配构建，不把源码示例自动等同于现机发行包 |
| 行走、坐站等部署包 | 待核定 | 各用途、合同、文件摘要、使用许可和回退版本 |
| HD1910 ONNX 回放与打包工具 | 待提供并验证 | 基线通用 infer_policy 默认仍有 XL330 路径，不作为飞特等效回放 |
| HOME 与机械零位 | 待核定 | 两套独立图示/参数，与当前模型对应 |
| 摄像头发行配置 | 不作为首轮默认功能 | 失联原因未查明，媒体组合未通过本机验收，不默认开启 |

公开的个人非商业复刻镜像不直接作为收费套件附件。本教程没有制作新的可交付系统镜像或行走模型。

## 2. 补拍真实界面与瑞莎安装图

- [ ] 一颗舵机接外置调试板、外接电源、真实串口选择。
- [ ] 改 ID、断电复查、真实输出轴点动的界面与实物对照。
- [ ] 瑞莎＋HAT 在本套件头/躯干内的固定、散热与绝缘方式。
- [ ] 本批次 J13 转接线两端近照，标出看图方向与 DATA/VCC/GND。
- [ ] IMU 刚性安装位置和轴向，电池与线束固定。
- [ ] 机械零位与当前模型 HOME 的正面、侧面图。
- [ ] 当前发货版本 Studio 的中位、IMU、写入成功、模型选用界面。
- [ ] 地面站立、坐下、短距离行走和停止的实物验收视频。

不使用 AI 生成的接口/针序图代替真实板卡证据。已有装配 PDF 图可辅助结构说明，不替代本套件电控照片。

## 3. 实物验收

- [ ] 先停用未验收媒体服务，查清并解决 SSH 异常。
- [ ] 冷启动、空闲、正常重启与持续运行后，SSH/Studio 均稳定。
- [ ] 动作负载下电压、温度、控制节拍、总线持续回读合格。
- [ ] 15 颗关节身份、真实输出轴、方向、零位与限位核对通过。
- [ ] IMU 数据、方向和主程序验证通过。
- [ ] 标定写入、退出标定模式、重启持久化通过。
- [ ] 卸力、站立、坐下、落地行走、停止按记录表完成。
- [ ] 若交付摄像头，另做编码、WebRTC 真实帧、负载与自启动验收。
- [ ] 用一套干净系统/新用户流程走查，确认不依赖开发者电脑私有路径和密钥。
