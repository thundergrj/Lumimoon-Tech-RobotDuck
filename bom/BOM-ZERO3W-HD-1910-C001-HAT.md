# Microduck BOM：ZERO 3W + HD-1910-C001 + HAT

[教程首页](../README.md) · [01-物料清单](../docs/01-物料清单.md) · [03-装配与接线](../docs/03-装配与接线.md)

版本：2026-11-02。本清单按用户指定的 **瑞莎 Radxa ZERO 3W、飞特 HD-1910-C001、机器人 HAT** 编写；沿用教程中的 IMU to DXL（ID 200）与 2S 供电主线。

文中的“HD1910”均指 **HD-1910-C001**。其他型号后缀、舵机固件和外观相近的扩展板不能不经核对替换。HAT 的具体型号、PCB 修订号和额定值仍需登记；接口说明暂对应前文使用的 J13/J14 TTL、J11/J3 四针参考板，不把未知 HAT 视为已经兼容。

数量是**一台机器**的装机需求，不含库存备品。标为“参考数量”的项不能直接当作已冻结的采购数量；有配件随主件附送时，不重复采购。

### 两个数量不能省略

- 舵机是 **15 颗**：10–14、20–24、30–34。IMU 地址 200 不占舵机数量。
- E11、E12、E13 是三类线。不能因为套件有“15 根舵机线”就认为 HAT 转接和 IMU 接线也已齐全。

读卡器、电脑和台架工具见 C 表，属于准备工具，不一定每台机器都随货配置。

## HD-1910-C001 采购与验收参数

来源：[厂家规格书 A/0，2026-09-07](../resources/HD1910%20开源资料/规格书/HD-1910-C001串型规格书-20260907.pdf)。以下为规格书参数，不是本机实测结果。

| 项目 | C001 参数 | 使用说明 |
| --- | --- | --- |
| 完整型号 | HD-1910-C001 | 保留后缀，不用只有“HD1910”的照片代替型号确认 |
| 工作电压 | 4–8.4 V | 同时满足 HAT、IMU 和连接器允许范围 |
| 典型电压 | 4.8 / 6 / 7.4 V | 本教程 2S 供电按配套设计使用 |
| 空载电流，7.4 V | ≤210 mA | 空载值不能作为承重站立或整机电源的选型依据 |
| 额定电流，7.4 V | 900 mA | 不能继续沿用旧文单颗 500 mA 的整腿估算 |
| 堵转电流，7.4 V | 2 A，规格书标注 ±10% | 峰值/故障工况，不是允许持续工作的目标 |
| 额定负载，7.4 V | 3.7 kg·cm | 与堵转扭矩区分 |
| 堵转扭矩，7.4 V | 15 kg·cm，规格书标注 ±10% | 不作为连续承载能力使用 |
| 外形/质量 | 34×20×23 mm；21±2 g | 核对外壳、输出轴和固定孔是否适合结构 |
| 输出轴 | 25T / OD 4.95 mm | 使用匹配舵盘与附件 |
| 连接器 | AMP2.0-3P | 按厂家看图方向辨识针号 |
| 针序 | 1 DATA、2 VCC、3 GND | 与参考 HAT J13 的 1、3 脚相反 |
| 出厂通信 | ID 1、1 Mbps、8N1 | 单颗确认后再编号并断电复查 |
| 中位/单圈范围 | 2048；0–4095 | 不等于整机 HOME，也不代替关节机械限位 |
| 运行模式 | 规格书包含模式 4“纯位置 PD（Sim2Real）”，并标注出厂默认 | 运行时、上位机和实际固件须核对，不能套用只列模式 0–3 的其他系列表 |

整机供电要把实际动作负载、主控与 HAT 功耗、连接器能力、线损和保护配合一起核算。不能用 USB 电源上的电流标称代替验证，也不能只把空载电流相加后就宣布整机供电合格。

舵机工作电压下限也不是电池允许放电的下限。2S 电池的低压停止、保护和充电条件按所选电池及保护方案执行，不能因为舵机参数写有 4 V 就把电池放到 4 V。

## HAT 与转接线验收

- [ ] 型号、PCB 修订号、正反面照片、对应原理图已保存。
- [ ] 已确认与 ZERO 3W 的 GPIO/UART 映射和 5 V 供电路径，排针不反插、不偏排。
- [ ] 接口输入范围允许电池满电电压，降压输出、端子和线材满足整机需要。
- [ ] 如沿用前文参考板，J13 为 1 GND / 2 +BATT / 3 DATA；C001 端按 DATA/VCC/GND 对应转换。
- [ ] J13 转接线逐根量通断；没有把 DATA/GND 交叉误做成电源正负反接。
- [ ] IMU 不承担未经核验的整腿过线电流。

## 采购和装箱怎么使用本表

先锁定 E01–E04 的具体硬件和结构版本，再统计线束长度、机械孔位与数量；确认随主件附送的配件后补缺。装箱时填写[装机与验收记录](../docs/附录/装机与验收记录.md)，把“缺件”“未核对”“已核对”分别记录。

HAT 版号、电源额定值、线束长度、结构五金数量未核对时，保持相应项未冻结，不用旧 Arduino 方案或其他 HD1910 批次补空。
