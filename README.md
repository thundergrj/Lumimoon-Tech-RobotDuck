# Microduck 客户组装与调试教程

从清点零件、逐颗编号，到整机装配、标定和首次试走，按下面八章顺序完成。每章都有操作条件、具体步骤、合格标准和异常处理。

![Microduck 机械装配参考](assets/03_assembled_duck.jpg)

## 适用套件

电控主线：**瑞莎 Radxa ZERO 3W + 配套 HAT + 15 颗飞特 HD-1910-C001 TTL 舵机 + IMU to DXL 总线板（ID 200）+ 2S 电池或配套稳压电源**。摄像头、语音、手柄等在基本动作稳定后逐项启用。

本教程后文“HD1910”均指 **HD-1910-C001**。采购与装箱使用[本套硬件 BOM](bom/BOM-ZERO3W-HD-1910-C001-HAT.md)，不再使用 Arduino Uno Q 电控清单；HAT 型号/PCB 版号、线束与结构五金数量按实际批次登记。

先核对随货硬件与软件版本。接口相似不代表针序、供电和协议相同。本仓库的 Arduino Uno Q 资料用于结构参考，其电控 BOM 不能直接代替瑞莎方案。

Studio 是操作界面，真正管理舵机、IMU 和策略的是主控上的 `robotd`。仿真训练则在训练电脑上进行。

## 开始前记住四件事

1. **中位不等于 HOME。** 中位常为 2048，HOME 是与模型匹配的一组关节角，不能把“全部回 2048”当成站立命令。
2. **按钮按下不等于动作完成。** 同时检查主程序回读与实物；输出轴没动时，数字变化不能代替机械验收。
3. **接管总线前先卸力、扶稳。** 用 Studio 接管和交还，不让扫描脚本与 robotd 抢串口。停止或重启服务不能代替卸力确认。
4. **先基础功能，后扩展。** 摄像头先验证采图、编码、网页帧与联网稳定，再考虑自启动。采到一张照片不等于网页视频可用。
